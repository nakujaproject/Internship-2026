
# One-Grain Static Test Motor

This repository/folder contains the design files for a **one-grain static test motor**. It includes manufacturing drawings and the native CAD project for editing.

## Working Drawings (PDFs)

The following manufacturing-ready drawings are provided:

- **`bulkHead_94mm.pdf`** – Bulkhead drawing (94 mm Casing Inner Diameter)
- **`casing_258mm.pdf`** – Casing drawing (258 mm Long)
- **`nozzle_94mm.pdf`** – Nozzle drawing (94 mm Casing Inner Diameter)

These PDFs serve as the primary reference for fabrication.

## Editing the Design Files

To modify the parametric 3D models:

1. **Install Autodesk Inventor** (any recent version compatible with the project files).
2. **Download the entire folder** `"one-grain static test motor"`.
3. **Open the project file**:  
   **`One-Grain Static Test Al-Motor 2026.ipj`**

Opening the `.ipj` project file will automatically link and load all associated part (`.ipt`) and assembly (`.iam`) files for editing.

### Recommended Workflow
- Use the project file to maintain proper file references and search paths.
- Make changes to individual parts/assemblies as needed.
- Update drawings (.idw) if dimensions or views require revision.
- Export updated PDFs or STEP files for manufacturing.
